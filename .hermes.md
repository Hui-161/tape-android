# Tape — Hermes Project Context

Hermes reads `.hermes.md` (this file) at session start. Same project, slightly different
framing than `.vscode/CLAUDE.md` because Hermes is the always-on coordinating agent, not just
an editor copilot.

## What this project is

Tape — free Android AR measurement app. Two taps, one distance, no subscription, no ads.

- Package: `com.tape.measure`
- Min SDK: 24, Kotlin 2.0.21, Jetpack Compose, ARCore, Hilt
- Status: pre-alpha, in active planning

## Why it exists

iOS has had a built-in Measure app since 2018. Android doesn't. Paid AR measurement apps
charge ₹300–2,000/yr and lock basic features behind subscriptions. Free ones are stuffed
with ads and dark-pattern upsells. Tape is the fix.

## Design principles (non-negotiable, in priority order)

1. One job, done well. Measurement. That's it. No feature creep.
2. Free forever. No subscription, no premium tier, no upsells.
3. Honest about accuracy. Show confidence badges. Explain errors. Don't oversell precision.
4. Respect the user's time. Two taps → distance. No tutorial walls.
5. Respect the user's data. No account. No analytics on what you measure. Local-first.

If any user request (including Akshay's) would cross these — push back, don't comply.

## Architecture and stack

- Kotlin 2.0.21 · Jetpack Compose 2024.09.03 · ARCore · Hilt (DI) · KSP · kotlinx.serialization
- MVVM + UDF: Compose UI, ViewModels emit `StateFlow<UiState>`, screens observe
- ARCore for camera + plane detection; show honest "unsupported" UI if device lacks ARCore
- Local persistence (Room or simple file) — no analytics, no remote sync

## Visual identity (golden rule)

**All token colors come from the runtime palette.** Every hex in the IDE theme
(`.vscode/themes/tape-warm-amber.json`) and in any HTML/design mockup should also appear
in `app/src/main/java/com/tape/measure/ui/theme/Color.kt`. When proposing visual changes,
always source from Color.kt — never invent a new palette.

Palette anchors:
- Accent (warm amber): `#E89B3C`
- Surface (warm near-black): `#0F0E0C`
- Foreground (warm bone): `#F4ECDF`
- Cursor / highlight (warm gold): `#FFC857`

## Build commands

```
./gradlew assembleDebug       # build APK
./gradlew installDebug        # build + install on connected device
./gradlew test                # unit tests
./gradlew lint                # Android lint
```

ARCore-capable device or emulator required for the app; CI builds OK without.

## Working agreements

- **Match repo conventions:** 4-space Kotlin indent; Compose `Modifier` first; small
  composables; prefer `derivedStateOf` over nested recomposition.
- **No paywall, ads, or analytics SDK.** Push back on requests that cross this line.
- **Min SDK 24 floor.** Don't pull in libs that require higher.
- **Sync Color.kt ↔ editor theme.** When Color.kt changes, `.vscode/themes/tape-warm-amber.json`
  must change in the same commit.
